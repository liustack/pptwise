A theme copy that keeps a built-in theme's id and offers `one-evidence` for `evidence` no longer gets a page whose subheading or source line runs off the edge or is cut with no mark. That theme's own version of the layout now sets the heading, subheading and source line whole at its usual sizes, or hands the page to the shared `one-evidence` layout, which marks anything it still has to cut. On lecture, a subheading beside an exhibit, which that version had no room for and left off the page, now goes to the shared layout too.
