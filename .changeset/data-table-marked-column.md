A `data_table` column can be marked as the one the page is about (`columns[].emphasis`) and can carry an icon set before each of its cells (`columns[].icon`, a left-aligned column only). The ordinary table sets the marked column's header and cells bold in the primary colour and outlines the column; validate refuses two marked columns. Hand-set tables hand such a page to the ordinary table.
