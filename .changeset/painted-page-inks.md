A page you give its own background now carries the theme's text, cards and rules onto it. Before, only the heading noticed: on a light theme with a page painted near-black, paragraphs, lists, cards and table text stayed in the theme's dark ink and could not be read. Now each of them keeps the contrast it had on the theme's own page, so a dark page reads like the theme's dark version and a light page on a dark theme like its light one. A page tinted only slightly, where the theme's text still reads, renders exactly as before. The theme's brand colours do not change.
