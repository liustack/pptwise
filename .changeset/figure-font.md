A theme can name a figure font, `fonts.figure`, for the large numbers on its pages. A theme that names none sets them in its heading font, as before. Bahnschrift, the DIN face Windows ships, joins the fonts slides can be set in, measured at its real widths, and a stack that names DIN Alternate first previews in it on a Mac.
