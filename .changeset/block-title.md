A `data_table`, a `comparison` and a `timeline` take an optional `title`, the name a report gives a table ("Free cash flow"). It prints over the block in bold, and a theme that sets the block in a panel prints it in the panel's title bar. A hand-set table or timeline with no place for a title leaves the page to the ordinary block, which prints it.
