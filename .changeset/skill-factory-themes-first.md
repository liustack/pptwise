The skill now picks from the factory themes by default and creates a theme only when the user names brand colors or hands over a company template or deck. Asked for a "cool" deck, a model used to fork a factory theme into a new color set of its own, which skips the per-page tuning the factory themes carry. A wish for a look now puts fitting themes on the theme wall instead.
