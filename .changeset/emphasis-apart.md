A marked run (`**…**`) always looks different from the words beside it. vermilion now marks a run in its red, where the run used to fall back to its gold, which is kept for rules and is too faint to read as text: a marked phrase in a comparison was the hardest one on the page to read. And a run whose emphasis colour is the colour of the line it sits in, such as a mark inside vermilion's red title or luxe's gold one, now takes the theme's text ink instead of vanishing into its line.
