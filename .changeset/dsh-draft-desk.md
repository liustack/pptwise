On DeepSeek Harness each finished turn that made a deck now ends with a draft card that stays open below the turn, Code Mode included: every page as a thumbnail, the page count and which version of the deck this is (one version per turn, however many times the turn rebuilt it), the pages changed since the last version marked, and buttons to view it full screen, download the .pptx, compare it with the last version side by side, or start a message about one page ("Page 3: " goes into the input box, ready to type). A turn that only drew an outline or a theme wall keeps that card below the turn instead. While pages are still being written, the build card says how many are done.
