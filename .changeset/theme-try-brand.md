`pptwise theme try --title <text> --brand <hex>[,<hex>]` adds one more option to the theme wall: the first theme on it repainted in the brand's colors, the same repaint `theme fork --brand` writes. Its row is `<theme>-brand` and carries `base` and `brand`, everything `theme fork <base> --brand` needs to bind it. Nothing is bound.
