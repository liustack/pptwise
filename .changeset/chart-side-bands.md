A bar chart on its side can mark value ranges (`bands`), as a line, an area and an upright bar already could, such as what a value below zero means: `[{ "from": -0.4, "to": 0, "label": "← Screens did worse" }, { "from": 0, "to": 0.1, "label": "Print did worse →" }]`. The ordinary chart tints each range down the rows and names it in a row over the plot, and its value axis grows to hold the ranges.
