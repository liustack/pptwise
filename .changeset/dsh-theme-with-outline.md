The DSH plugin settles the theme together with the outline. `pptwise_themes` is called once the spec validates, before any page is written, and its result asks the user in the same message as the outline and the picture direction. It takes `brand`, the brand colors `pptwise brand scan` found, and then ends the wall with one more option: the first theme repainted in those colors, captioned in the card by its color swatches and the theme it repaints, with the `theme fork` line that binds it. The plugin's instructions now run the brand scan while gathering materials, build with `sheet: true` once a build passes, and take the user's and the project's own pictures, pinned with `images add`, before stock search.
