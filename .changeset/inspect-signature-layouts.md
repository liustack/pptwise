`pptwise inspect <deck> --page <id>` now lists the theme's signature layouts for the page: the drawings the theme's own samples are made of, the ones made for the page's kind first (or for the kind it lands on), each with how it looks and the recipe a page is written to for it, the components, item counts and fields it takes. A cover, chapter or ending whose face draws over a photograph lists that photograph. A written page is drawn and the layout that draws it now is marked, or the report says the face draws it plain. `--json` carries the same facts under `signature`.
