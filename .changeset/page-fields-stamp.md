A page can carry `fields`, one to four header lines a document form prints (a label, a value and an optional note, such as a memo's To, From, Date and Re), and a `stamp` pressed on the page (its words and an optional date). Both live in the page file. Like `kicker`, only a face that declares a place for them draws them, and validate refuses them on any other face, naming it.
