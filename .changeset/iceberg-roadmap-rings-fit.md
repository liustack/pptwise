An iceberg's tip line now sits a few pixels above the waterline instead of resting on it. A roadmap no longer marks a short period such as "Q1" as cut, sets each row value on the same baseline as its label, and gives a long row label the room its short values leave, or a second line, instead of cutting its end off. Rings in a narrow box, such as the side panel of a three-part page, now keep a label column wide enough for their labels and print every description in full, with the core growing a little when it needs to hold its own name. When the box is still too short, the page moves to a layout with more room instead of cutting text or leaving a line off the bottom. Rings that already fit render exactly as before.
